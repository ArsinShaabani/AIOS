# AIOS v1.2.1 — installer hotfix

## Fixed
- `install.sh` downloaded `aios-linux-<arch>` while releases publish
  `aios_<version>_linux_<arch>` → HTTP 404 on fresh installs. The installer now
  tries both naming schemes, so old and new releases work.
- SHA-256 verification now reads `SHA256SUMS-<version>.txt` (the published
  checksum file) as well as per-asset `.sha256`, and warns instead of silently
  skipping when absent.
- 32-bit Raspberry Pi (`armv7l`) is detected and installs the `armv7` asset;
  armv6 gets an explicit, actionable error.
- Installer config now uses an 8 MB request body and an 8k prompt budget to match
  the v1.2 model/context options.

## Install
```bash
curl -fsSL https://github.com/ArsinShaabani/AIOS/releases/latest/download/install.sh \
  | sudo bash -s -- --admin-password 'Choose-A-Strong-Password'
```

Upgrade an existing install: add `--upgrade`.
Offline: `--local-binary ./aios_1.2.1_linux_amd64`.
