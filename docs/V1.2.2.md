# AIOS v1.2.2 — simpler chat controls

- Chat now shows a single **Reasoning effort** selector (auto / low / medium / high)
  next to the model picker.
- Removed per-chat Max tokens, Temperature and Context window fields. Those values
  are read from the provider/model configuration in **Models**, so switching models
  keeps the right limits automatically.
- Any previously stored per-chat overrides are dropped on the next effort change,
  so stale values cannot cap long answers.
