# AIOS v1.3.0 — Bring your own AI

## Highlights

- **Per-user AI providers (BYOK).** Users add Ollama, Groq, Gemini, OpenRouter,
  OpenAI, Anthropic or custom OpenAI-compatible endpoints under «هوش مصنوعی من».
  Upstream keys are AES-GCM encrypted and never returned by the API.
- **OpenAI-compatible tunnel.** `POST /v1/chat/completions` and `GET /v1/models`
  accept an AIOS key bound to a provider/model. Streaming, tools, usage and the
  OpenAI error envelope are supported; the upstream key stays server-side.
- **Chat uses the user's model.** The built-in chat model picker now lists the
  caller's providers and routes the turn through the chosen provider.
- **Self-registration.** `POST /api/v1/auth/register` (toggle with
  `security.allow_registration`); the dashboard has a sign-up screen.
- **Full backup/restore.** Admin backup downloads users, settings, keys, personal
  providers, devices, personalities, agents, plugins and (optionally) all chat
  data as one JSON file; restore is transactional and replace-mode.
- **Richer devices.** Connection method, hardware, room, tone, response style,
  language, preferred provider/model, requirements and description.
- **Dashboard.** Right-side (RTL) navigation, Persian onboarding, help page,
  My AI page, user role/status/password actions and backup UI.
- **Longer answers.** Default output 4096 tokens and 8192-token context
  (per-provider `max_tokens`/`context_window` overrides).
- **2 GB / 2 vCPU profile.** `GOMEMLIMIT=768MiB`, `GOGC=50`, `GOMAXPROCS=2`,
  `MemoryHigh=1500M`, `MemoryMax=1800M`.

## Upgrade

```bash
sudo ./install.sh --upgrade
# migration 0005 adds user_providers and API-key routing columns automatically
```

Existing API keys keep working unbound (they use the server default provider).
Backups restore encrypted secrets only on a host with the same keyring; copy
`/var/lib/aios/keys/` when migrating.

- Added the missing **Coqui TTS** (`coqui_http`) and **Azure Speech** (`azure`)
  adapters, including `region`, `language`, SSML and output-format mapping.
- Added a browser API reference at **`/docs`** backed by the embedded OpenAPI spec.
- Exposed the **Characters** editor and a dedicated **Security** panel in the
  right-side navigation.
- Published [`REQUIREMENTS.md`](REQUIREMENTS.md): every master-prompt item mapped
  to Done/Partial/External with evidence and explicit limitations.
